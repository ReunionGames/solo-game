# Chronicles of the Kingdom — Solo Game

The web solo game (Endurance mode) for [Chronicles of the Kingdom](https://www.chroniclesofthekingdom.co.uk/).

This repository hosts the game so new modes and updates can go live without pasting into the Wix editor. The website itself is unchanged until the embed is pointed here.

Play this copy: https://reuniongames.github.io/solo-game/
